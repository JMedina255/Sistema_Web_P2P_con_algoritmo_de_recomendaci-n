# Evidencias: Plataforma GitHub Classroom

## 📌 Descripción
Espacio reservado para almacenar las evidencias gráficas y registros del uso de la plataforma **GitHub / GitHub Classroom** en el marco del curso **Construcción de Software I**.

## 📁 Contenido Previsto
* Capturas del repositorio grupal y configuración de colaboradores (docente y estudiantes).
* Historial de commits, ramas y trazabilidad del trabajo colaborativo.
* Evidencias de entrega y asignación de actividades.
