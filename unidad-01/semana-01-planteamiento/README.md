# Semana 01: Planteamiento del Problema y Proyecto

## 📌 Descripción
Definición inicial de la problemática, formulación de la solución y planteamiento del proyecto *Sistema Web P2P con algoritmo de recomendación para la personalización de mentorías académicas en la EPIS-UPT*.

## 🎯 Objetivos de la Semana
* Identificar la problemática de reprobación y deserción en asignaturas formativas básicas y críticas.
* Formular la propuesta de conexión P2P entre estudiantes destacados (mentores) y estudiantes de ciclos iniciales (mentoreados).
* Establecer el alcance preliminar y objetivos generales/específicos del proyecto de software.
