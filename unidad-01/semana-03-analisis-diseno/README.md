# Semana 03: Análisis y Diseño Preliminar

## 📌 Descripción
Fase inicial de modelado de procesos, flujos de información y diagramas preliminares del sistema de mentorías académicas P2P.

## 🎯 Objetivos de la Semana
* Identificar los flujos clave de interacción entre mentores y mentoreados.
* Generar los primeros diagramas de actividades y procesos del sistema.
* Sentar las bases para la formalización de requisitos y documentos FD01 y FD02.
