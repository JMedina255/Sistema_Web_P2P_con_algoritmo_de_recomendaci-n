# Semana 01: Métricas de Software

> **Curso:** SI-983 Construcción de Software I (Semestre 2026-II)  
> **Proyecto:** Sistema Web P2P con algoritmo de recomendación para la personalización de mentorías académicas en la EPIS-UPT  
> **Equipo (Grupo 03):** Renzo Antonio Antayhua Mamani & Joan Cristian Medina Quispe  

---

## 📌 1. Descripción de la Actividad
Estudio, definición e instrumentación de métricas de software orientadas al aseguramiento de la calidad, complejidad ciclomática, cobertura de pruebas unitarias/integración, latencia algorítmica y esfuerzo de desarrollo en la solución P2P.

## 🎯 2. Objetivos
* Establecer el marco de medición cuantitativa del software alineado a la norma ISO/IEC 25010.
* Instrumentar métricas de cobertura de código (threshold >= 70% conforme a RNF09).
* Monitorear latencia algorítmica de recomendación (RNF03 < 50 ms) y tasa de sobrecupo (RNF07 = 0.00%).
