# Semana 06: Sprint 06 — Evaluación de Quórum, Asistencia TOTP y Bitácoras

> **Curso:** SI-983 Construcción de Software I (Semestre 2026-II)  
> **Proyecto:** Sistema Web P2P con algoritmo de recomendación para la personalización de mentorías académicas en la EPIS-UPT  
> **Equipo (Grupo 03):** Renzo Antonio Antayhua Mamani & Joan Cristian Medina Quispe  

---

## 📌 1. Alcance del Incremento
Corte automático de quórum en T-24h (RF15 / CUS23 / RN-09), panel de resolución de contingencias para el mentor (RF16 / CUS07), proyección interactiva de código QR dinámico y TOTP de 6 dígitos con expiración de 30 segundos (RF17 / CUS12 / RN-12), check-in de asistencia digital en tiempo real y formulario estructurado de bitácora pedagógica con sello de integridad SHA-256 (CUS08).

## 📊 2. Métricas de Calidad
* **Pruebas automatizadas:** 465 pruebas automatizadas satisfactorias (277 frontend y 188 backend).
* **Cobertura:** 83.25% frontend y 87.42% backend.
