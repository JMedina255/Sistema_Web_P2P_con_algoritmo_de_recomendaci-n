## 📌 1. Descripción de la Actividad
Grabación y presentación audiovisual que demuestra el funcionamiento end-to-end del Sistema Web P2P, cubriendo los flujos esenciales de mentor, mentoreado y administrador.

## 🎯 2. Guion de Demostración Previsto
1. **Acceso institucional:** Autenticación OTP con dominio `@upt.pe`.
2. **Consentimiento digital:** Aceptación informada conforme a la Ley N° 29733 (RF02).
3. **Perfil y disponibilidad:** Configuración de agenda semanal 6×11 con validación de mérito (RF04 / RN-03).
4. **Publicación docente:** Creación de sesión con temario silábico, control de antelación y aforo (RF08 / RN-04 / RN-05).
5. **Feed EdRecSys:** Recomendación inteligente Top-k con tarjetas explicables XAI (RF06 / CUS02).
6. **Reserva ACID:** Reserva transaccional con bloqueo pesimista y corte de quórum T-24h (RF12 / RF15).
7. **Asistencia TOTP y Bitácora:** Proyección de QR/TOTP dinámico y registro pedagógico con sello SHA-256 (RF17 / CUS08).
