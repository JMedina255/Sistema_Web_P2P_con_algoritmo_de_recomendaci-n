# Semana 05: Sprint 05 — Ratificación, Desistimiento y Control de Asistencia

> **Curso:** SI-983 Construcción de Software I (Semestre 2026-II)  
> **Proyecto:** Sistema Web P2P con algoritmo de recomendación para la personalización de mentorías académicas en la EPIS-UPT  
> **Equipo (Grupo 03):** Renzo Antonio Antayhua Mamani & Joan Cristian Medina Quispe  

---

## 📌 1. Alcance del Incremento
Módulo de ratificación obligatoria de reserva antes de la ventana crítica T-24h (RF13 / CUS24 / RN-08), flujo de desistimiento voluntario con liberación atómica de cupo (RF14 / CUS04-A), y actualización reactiva de aforos disponibles.

## 📊 2. Métricas de Calidad
* **Pruebas automatizadas:** Verificación de integridad transaccional multihilo y actualización atómica en base de datos.
* **Cobertura:** Mantenimiento de cobertura global > 85%.
