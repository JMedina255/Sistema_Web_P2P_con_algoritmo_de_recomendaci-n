# Semana 04: Sprint 03 — Publicación de Ofertas y Motor EdRecSys

> **Curso:** SI-983 Construcción de Software I (Semestre 2026-II)  
> **Proyecto:** Sistema Web P2P con algoritmo de recomendación para la personalización de mentorías académicas en la EPIS-UPT  
> **Equipo (Grupo 03):** Renzo Antonio Antayhua Mamani & Joan Cristian Medina Quispe  

---

## 📌 1. Alcance del Incremento
Formulario reactivo de publicación de ofertas con carga dinámica silábica (RF08 / CUS06), control de antelación obligatoria > 24 h (RN-04), aforo estándar inmutable de 10 presencial y 20 virtual (RN-05), asignación de aulas EPIS (RN-06) o Meet (RN-07), y motor de recomendación Top-k EdRecSys v1.0 con simulación algorítmica testbench.

## 📊 2. Métricas de Calidad
* **Pruebas automatizadas:** 209 pruebas consolidadas sin fallos.
* **Latencia algorítmica:** 35.8 µs por candidato (0.86 ms total, superando RNF03 < 50 ms).
