# Semana 03: Sprint 01 — Base Técnica, Acceso Inicial y CI

> **Curso:** SI-983 Construcción de Software I (Semestre 2026-II)  
> **Proyecto:** Sistema Web P2P con algoritmo de recomendación para la personalización de mentorías académicas en la EPIS-UPT  
> **Equipo (Grupo 03):** Renzo Antonio Antayhua Mamani & Joan Cristian Medina Quispe  

---

## 📌 1. Alcance del Incremento
Puesta en marcha del entorno ejecutable integral, enlace frontend SPA (React 19) con backend RESTful (FastAPI), conexión con PostgreSQL/Supabase, flujo de acceso OTP institucional (`@upt.pe`) y pipeline automatizado de integración continua en GitHub Actions.

## 📊 2. Métricas de Calidad
* **Pruebas automatizadas:** 96 pruebas superadas (100% de éxito).
* **Herramientas de testing:** Pytest (backend) y Vitest (frontend).
* **Pipeline:** GitHub Actions CI limpio con linters (Ruff y ESLint).
